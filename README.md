# Анализатор сети с GUI

Приложение на Python/Tkinter для:

- TCP-сканирования портов по IP/подсети;
- выполнения одиночных сетевых запросов (DNS, HTTP, TCP);
- отображения истории сканирований в интерфейсе (JSON);
- отображения и сохранения истории запросов в SQLite.
- экспорта истории запросов в CSV/JSON.

## Используемые библиотеки

- `tkinter`, `ttk` — графический интерфейс;
- `threading`, `queue` — фоновая обработка задач;
- `socket`, `ipaddress`, `urllib.request` — сетевые операции;
- `json`, `sqlite3` — хранение истории;
- `datetime`, `os` — служебные задачи.

## Запуск

```bash
python3 Test.py
```

## История данных

- Сканирования сохраняются в файл `scan_history.json`.
- История сетевых запросов сохраняется в `request_history.db`.
